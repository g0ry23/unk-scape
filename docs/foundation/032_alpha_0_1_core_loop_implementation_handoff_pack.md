- Player spawns.
- Player can move to a resource node.
- Player can gather from the node.
- Inventory receives the item with correct ID and quantity.
- XP is granted from a valid source.
- Save captures the result.
- Load restores the result.
- UI shows what happened.
- No duplication through rapid clicking.
- No save corruption.
- No XP corruption.
